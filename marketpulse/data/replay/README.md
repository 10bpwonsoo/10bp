# 로컬 CSV 리플레이

여기 `<instrument_id>.csv` 를 넣으면 해당 종목은 이 파일에서 읽는다.
`sources.yaml` 을 고칠 필요가 없다 — 파일이 있으면 자동으로 마지막 후보로
붙고, 네트워크 공급자가 전부 실패하면 여기로 떨어진다.

세 가지 상황에서 쓴다.

1. **네트워크가 막힌 환경.** 조직 정책으로 마켓데이터 호스트가 차단되면
   이것이 유일한 실데이터 경로다.
2. **무료 API 가 없는 계열.** breadth(상승종목 비율, 신고가-신저가)는
   종목 전체를 훑어야 나와서 무료 공급자가 없다.
3. **시연 재현.** 같은 파일이면 같은 화면이 나온다.

## 형식

```csv
date,close
2026-01-02,4.21
2026-01-03,4.26
```

- 열 이름은 `date`/`close` 또는 `일자`/`종가` 를 받는다.
- 날짜는 `YYYY-MM-DD`, `YYYYMMDD`, ISO 8601 을 받는다.
- 최소 20행이 필요하다. 그보다 짧으면 z-score 의 분모가 잡음이다.
- 단위는 `instruments.yaml` 의 `unit` 을 따른다. 금리는 `4.21`(퍼센트)이지
  `0.0421` 이 아니다.

## 확인

```bash
.venv/bin/python -m marketpulse.cli probe --mode DELAYED
```

종목별로 어느 공급자가 쓰였는지, 실패했다면 왜인지 표로 나온다.
